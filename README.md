# Code Together

A social s&box game where you can cowork with others, stream your screen, play minigames, and socialize. It was created to give s&box devs a place to socialize and interact to keep each other motivated, but also just because it's fun.

Play it on s&box: https://sbox.game/bionicbooger/code_together

## Streaming

To stream your screen you'll need the companion tool, **CT Screen Server**, a small Windows app that captures your screen and broadcasts it over a local WebSocket. The game connects to it automatically when you start streaming from an in-game monitor.

Get it here: [ct-screen-server](../ct-screen-server/README.md)

*As an aside, you can still join and play without it, you just won't be able to stream your own screen. The capture has to live in an external app because s&box's whitelist doesn't allow a game to grab your screen directly.*

## Requirements

- s&box (to play the game)
- Windows with the CT Screen Server tool (to stream your screen)
